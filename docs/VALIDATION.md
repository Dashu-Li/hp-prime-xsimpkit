## 本轮原生安装与代表性数学

在官方 Linux 2019 Virtual Calculator 2.1.14290 的新会话中，仅导入新版程序。安装前 `XSIMP`、`xspfpoly`、`xspfauto` 均为 `DOM_IDENT`，排除了旧函数已加载的情况。编辑器 Check 返回 `No errors`；运行 `XSIMPKIT187` 返回 `XSIMP 1.8.7 CHECK OK`，哨兵变量 `1729` 保留。

原生验证确认完整 `sqrt(D)` 及实际 `XSIMP(desolve(...))` 的通解均得到预期紧凑形式。直接代入 `a=-2,b=c=d=1` 的负判别式得到 `2.6457513106*i`；`sqrt((a+1)^2)` 直接代 `a=-3` 得 `2`。原有整数指数结果 `e^(i*a)` 保留，三角根式在 `a=pi` 得 `-i`，非整数指数反例在 `a=2*pi` 得 `+1`。

原生新增符号规则使用两个复数选项均关闭的配置；直接数值分支使用两个选项均开启的配置。原生并未遍历四种组合；四组合覆盖属于 HOST 检查。原生模拟器不按 G2 硬件速度运行，结果不构成 G2 实机或性能验证。安装与结果记录见 `native/NATIVE_VALIDATION.json`。

## 局部因式分解边界

- 只处理精确、未绑定变量的多项式块；尝试整体因式分解、改进已有乘积中的加法因子，以及按变量分组并分解系数。重命名变量的独立测例验证其不依赖截图中的变量名。
- 候选通过 `ratnormal(候选−原式)=0` 验证精确多项式恒等，并且实际显示更短时才采用。完整根号作为一个主值运算保留，不将 `sqrt(P*Q)` 拆成 `sqrt(P)*sqrt(Q)`。
- 截图判别式可写成 `(a+b)*(a*c^2+b*(c+2*d)^2)`；同一通解的 HOST 规范显示长度从 1.8.6 的 134 字符降至 1.8.7 的 118 字符，积分常量保留。原方程通解形式仍要求 `a+b!=0`；降阶情形不由化简器另解。
- 每次调用缓存最多 24 个多项式块，重复块复用缓存；缓存容量不限制遍历或分析的总块数。单块 512 字符、最多 5 个变量、分组时该变量的次数不超过 4、递归深度 2。超出预算时保留已有形式；这些预算不是原生 CAS 调用的硬超时，不构成 G2 提速保证。
- 新测试分别对候选与独立参考代值，再各自 `evalf`，包含负判别式、负参数和、零判别式和复参数；分支判断不以平方相等替代。完整输出和长度见 `partial-factor/`。

## 保留的数学保护

自然指数整数幂可合并；非整数幂保留自身主值，例如 `(exp(i*a))^(1/2)` 不能普遍改写为 `exp(i*a/2)`，`a=2*pi` 是变号反例。三倍角只在受限三角多项式中整理完整被开方数，并只提取正有理平方数。

`sqrt(cos(3*a)+3*cos(a))/(2*cos(a))` 可整理成 `sqrt(cos(a)^3)/cos(a)`，仍要求 `cos(a)!=0`；`a=pi` 时值为 `-i`，不能无条件继续约成 `sqrt(cos(a))`。高谐波与复杂角度保守跳过。较短原式仍参与标量候选选择；矩阵函数与闭精确复根计算保持特殊路径。

## 原生 CAS 再次求值的历史已知限制

1.8.6 在官方 Linux 2019 原生 CAS 的验证确认：Simplify 为 Minimum 或 None 时，首次受保护符号结果存入变量后再读取，原生 CAS 可能重算并改变主值。1.8.7 保留此限制；本轮未重新测试已保存变量再次读取的故障，不将历史反例写成本轮原生复现。

此前已验证的直接代值方式：

```text
evalf(subst(XSIMP("sqrt(cos(3*a)+3*cos(a))/(2*cos(a))"),a,pi))
evalf(subst(XSIMP("(exp(i*a))^(1/2)"),a,2*pi))
```

历史原生结果分别为正确的 `-i` 与 `1`；先保存符号结果再读取可能分别变成 `+i` 与 `-1`。普通输入进入 `XSIMP` 前也可能已由原生 CAS 求值，丢失的结构无法恢复。分支敏感输入建议使用字符串并直接代值；这不保证原生 CAS 后续任意操作保持分支，G2 行为未确认。

## 已知排除和适用条件

混合字符串/未知调用测例 `unknown_and_string_data` 仍是已记录的上游 JS 阻断项，排除且不计通过。此前复杂 `ln(a)` 矩阵用例中的上游边界也未扩展成本版通过项。

弧度制仍是三角/双曲转换的使用条件。旧 Degree/Grad 混合复双曲数值问题未由本版修复，也不计本版通过。分式消约沿用一般 CAS 约定；新增候选的分母检查不意味着整个旧管线跟踪全部原定义域。

`cholesky` 的厄米正定条件、`ismith` 的整数矩阵条件不由化简器改变。官方 2019 模拟器完整退出再打开后可能需要从程序目录重新运行安装器，不能据此推断 G2 休眠或保存行为。GitHub v1.8.7 发布日期：2026-10-28。
