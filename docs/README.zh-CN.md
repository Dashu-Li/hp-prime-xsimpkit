# XSIMPKIT：HP Prime 化简与矩阵函数

XSIMPKIT 为 HP Prime 的 CAS 提供表达式化简和矩阵函数。它可以整理分式、根式、复数、指数和三角表达式，也可以计算矩阵指数、正实常量底数的矩阵幂、矩阵正弦和余弦。

日常化简用 `XSIMP(表达式)`；计算矩阵函数时，也可以直接调用下面的函数。结果会尽量整理为较紧凑的幂、三角或双曲形式。

[下载安装包](https://github.com/Dashu-Li/hp-prime-xsimpkit/releases/tag/v1.7.0) · [English](../README.md) · [完整函数表](API.md)

## 常用函数

| 函数 | 用途 |
|---|---|
| `XSIMP(e)` | 统一化简入口，支持普通表达式、引用表达式和字符串输入。 |
| `XEXP(A)` | 计算矩阵指数 `exp(A)`。 |
| `XEXPT(A,t)` | 计算 `exp(t*A)`，其中 `t` 为标量。 |
| `XPOW(b,A)` | 计算矩阵函数 `exp(ln(b)*A)`，要求 `b` 为正实常量。 |
| `XSIN(A)`、`XCOS(A)` | 计算矩阵正弦、余弦。 |

矩阵函数要求输入方阵。`XRECT`、`XREWRITE` 及诊断函数的用法见[完整函数表](API.md)。`XFAST` 与 `XDEEP` 在 1.7 中使用同一套标量化简策略，后者没有额外的深度搜索。

## 使用示例

```text
XSIMP((x^2-1)/(x-1))
XSIMP(sqrt(8)-2*sqrt(2))
XSIMP((1+i)/(1-i))
XSIMP(e^((2-sqrt(3))*ln(2)))
XSIMP(e^([[1,1],[2,3]]*ln(2)))
XSIMP(e^(t*[[0,-1],[1,0]]))
XSIMP(e^(i*t*[[0,1],[1,0]]))
XSIMP(sin([[0,-1],[1,0]]))
XSIMP(cosh([[0,-1],[1,0]]))
```

前三项分别为 `x+1`、`0`、`i`；分式消去仍沿用 CAS 的通常约定，不保留原分母排除的点。第四项为 `2^(2-sqrt(3))`。

在上面的矩阵指数例子中，记 `u=sqrt(3)*ln(2)`，数学结果为：

```text
[[4*cosh(u)-4*sinh(u)/sqrt(3), 4*sinh(u)/sqrt(3)],
 [8*sinh(u)/sqrt(3),          4*cosh(u)+4*sinh(u)/sqrt(3)]]
```

实际输出写出完整参数，不创建 u 变量。实数系数会完成乘法和分式整理，不再留下 `2*sinh(u)*(1/sqrt(3))*4`。`8*sinh(u)/sqrt(3)` 与 `8*sqrt(3)*sinh(u)/3` 是允许的等价形式；有无引号不承诺逐字符相同。

符号旋转指数输出 `[[cos(t),-sin(t)],[sin(t),cos(t)]]`；纯虚 Pauli 指数输出 `[[cos(t),i*sin(t)],[i*sin(t),cos(t)]]`。矩阵 sine 保留适当的 sinh，矩阵 cosh 则在本例化为 `cos(1)` 的对角矩阵。

## 安装

1. 下载 Release 中的 `XSIMPKIT.hpprgm`，在 HP Connectivity Kit 中拖入已连接计算器的 Programs（程序）区域。
2. 传输后，按 Shift+CAS，将 Simplify（化简）设为 **None（无）**，使用精确模式、弧度制。Complex 可以开启。None 关闭的是原生界面对返回结果的再次自动化简，XSIMP 内部显式调用的化简仍会执行。本程序不会修改这些设置。
3. 在 CAS 输入 `XSCHECK(0)`，应返回 `XSIMP 1.7 CHECK OK`。计算调用 `XSIMP(...)`，不要传给安装容器 `XSIMPKIT()`。

## 复数矩阵指数

下面两种写法都保留精确输入，其中第二种不需要引号：

```text
XSIMP("exp(i*([[1,0],[1,1]]+2*[[0,-i],[i,0]]))")
XEXPT([[1,0],[1,1]]+2*[[0,-i],[i,0]],i)
```

令 `s=sqrt(2+sqrt(5))-i*sqrt(sqrt(5)-2)`，结果等价于：

```text
exp(i)*[[cos(s),2*sin(s)/s],[(-2+i)*sin(s)/s,cos(s)]]
```

实际显示可能采用等价的复参数或系数。`s^2=4-2*i`，无需数值近似。

`XSIMP(exp(...))` 的参数会先由原生 CAS 求值。如果这一步已经产生小数，XSIMP 无法还原丢失的精确原式；此时请用上述字符串输入，或直接用 `XEXPT(A,i)` / `XEXP(i*A)`。

标量复根也可用 `XSIMP("sqrt(4-2*i)")` 或 `XSIMP("(4-2*i)^(1/2)")`。当前精确构造针对高斯有理数；不支持的精确复根保留根式，不承诺化为最短的实部加虚部形式。

## 含变量底数的双曲形式

```text
XSIMP(e^([[1,1],[2,3]]*ln(a)))
XSIMP("e^([[1,1],[2,3]]*ln(a))")
```

令 `u=sqrt(3)*ln(a)`，两个路径均应恢复紧凑双曲形式，等价于：

```text
a^2*[[cosh(u)-sinh(u)/sqrt(3), sinh(u)/sqrt(3)],
     [2*sinh(u)/sqrt(3),       cosh(u)+sinh(u)/sqrt(3)]]
```

程序返回普通矩阵，公共系数可能分布在各元素中。该恒等式沿用原式的同一对数分支与定义域 `a!=0`，不需要额外假定 a 为正实数。恢复过程先直接整理原有指数；只有后备的幂转指数步骤新引入对数时，才使用原先的底数保护。未知分母仍不会被随意当成非零。

标量 `exp((2-sqrt(3))*ln(a))` 也能显示为 `a^(2-sqrt(3))`。识别时保持对数底数整体；不会把 `ln(a^2)` 拆成 `2*ln(a)`。

## 什么时候需要引用输入

无引号参数会先由原生 CAS 求值，再传给自定义函数。特别是 HP Prime 的 `2^矩阵` 会先按元素计算：

```text
XSIMP(2^[[1,1],[2,3]])
```

保留原生结果 `[[2,2],[4,8]]`，不会擅自把它解释成矩阵指数。如果本意是矩阵幂，可以写等价的矩阵指数：

```text
XSIMP(e^([[1,1],[2,3]]*ln(2)))
```

也可以保留原始输入结构；以下两种无需字符串引号，第三种为字符串用法：

```text
XSIMP(quote(2^[[1,1],[2,3]]))
XSIMP('2^[[1,1],[2,3]]')
XSIMP("2^[[1,1],[2,3]]")
```

输入前已经丢失的精确信息，程序无法恢复。

## 处理范围与限制

- 对矩阵元素的已求值结果，识别最多两个指数原子，改写为有界 Laurent 多项式，验证重构等价后比较双曲、三角候选和原式长度。实指数和符号/复指数均可处理。
- 分母是否非零不能确认时，新增恢复步骤放弃该候选。原式已有的 ln 不要求正实常量；幂转指数新引入的 ln 仍受保护，不拆分对数的底数。原有 CAS 化简约定仍适用。
- 统一整理数字乘法、分式系数、重复项，以及纯虚双曲函数转换后的三角函数偶奇性。避免对完成的实双曲结果再次整体 simplify 而重新展开。
- 有理特征值、对角矩阵、Jordan/幂零、普通矩阵乘方、列表和原有标量无理数指数仍有回归覆盖。负实底数矩阵幂继续拒绝，以免暗中选择复对数分支。
- 输入上限 1600 字符、递归深度 24 层；指数恢复另有更小的局部尺寸限制。这些不是硬超时，单次内置 CAS 操作仍可能耗时，也不是任意表达式的全局最简搜索。
- Maximum 设置可能重新展开程序返回的紧凑表达式。需要保留输出形式时，使用 None 设置。

验证环境、实际通过项和限制见 [TESTING.md](TESTING.md)。当前设备上的固件结果仍需以实际运行本版为准；本包的原生验证使用 HP 官方 2019 Linux Virtual Calculator。
